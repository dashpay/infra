# The archive keyring

`dashmate-archive-keyring.gpg` goes here when the repository's key is made
(`../../README.md`, "The key"): the public key, binary (`gpg --export`), with
both signing subkeys. It is the file operators get as
`/usr/share/keyrings/dashmate-archive-keyring.gpg`.

The publisher refuses to run without it, and refuses to publish anything this
keyring does not verify.
